# Capturas de proyectos

Coloca aquí las capturas reales. Formatos: `.png`, `.jpg` o `.webp`.

## Carpetas y nombres

| Carpeta | Proyecto |
|---|---|
| `restaurante-frontend/` | Sistema Restaurante Frontend |
| `bancario-frontend/` | Sistema Bancario Frontend |
| `restaurante-movil/` | Sistema Restaurante Móvil |
| `bancario-movil/` | Sistema Bancario Móvil |

En **cada carpeta** usa estos nombres (los lee el portafolio):

| Archivo | Uso |
|---|---|
| `hero.png` | Vista principal (portada de la tarjeta) |
| `dashboard.png` | Panel / flujo |
| `detail.png` | Detalle |
| `mobile.png` | Vista responsive / móvil |

Ejemplo:

```
public/assets/projects/restaurante-frontend/hero.png
public/assets/projects/restaurante-frontend/dashboard.png
...
```

Si falta un archivo, se usa el mock SVG automático.

### Tips
- Mejor proporción **16:10** o **16:9** (p. ej. 1600×1000).
- Capturas del navegador o del emulador móvil.
- Puedes usar `.jpg` o `.webp` cambiando la extensión en el store si prefieres.
